# Felicitación para 𝑶𝒔𝒊𝒓𝒊𝒔

Proyecto estático de GitHub Pages hecho como una felicitación poética por recibir su título.

La presentación contiene nueve escenas visuales, cada una construida alrededor de una frase del mensaje. Las primeras ocho usan gustos de 𝑶𝒔𝒊𝒓𝒊𝒔 como símbolos poéticos; la última mantiene la idea del universo alrededor de "TU SONRISA".
